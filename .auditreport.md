- Location: AffiliateFacet::callAsAffiliate (lines 246-270).
- Fix: Added selector allowlist checks so only approved Symmio calls can be forwarded.

- Issue: Any account owner could call Symmio admin-only selectors through AccountLayer.
- Location: CoreFacet::_call (lines 221-258), CoreFacet::_isForbiddenSelector (lines 263-272).
- Fix: Blocked admin selectors in _call via explicit blacklist.

- Location: AccountManager::withdrawFromAccount (lines 68-70), AccountManager::_withdrawFromAccount (lines 108-112).
- Fix: Added recipient-aware withdrawal (withdrawFromAccountTo) and routed default to msg.sender.
