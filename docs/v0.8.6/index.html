Symmio Core v0.8.6 Changelog

v0.8.6 adds credit-backed Express Withdrawal, AccountLayer delegated ownership controls, affiliate shutdown handling, Muon UPNL freshness overrides, PartyA liquidation funding snapshot fixes, and liquidation-fee recipient cleanup. The update is mainly about faster withdrawals, cleaner account administration, and safer liquidation settlement.

Changelog

Release highlights

Liquidation PartyA LF recipient

PartyA liquidation fee is paid only to the liquidation starter.

Price-setting and later liquidation calls no longer create extra LF recipients. The LF is paid only after final settlement, so the starter already has incentive to complete the liquidation flow. If a liquidator misbehaves, the protocol can deactivate that liquidator through role/admin controls instead of splitting LF across steps.

Events BalanceChange typing

Reimbursement credits now have their own balance-change type.

Clearing-house distributions routed into a liquidating PartyA's reimbursement bucket emit REIMBURSEMENT_IN instead of pretending the allocated balance received immediate realized PnL. This keeps event consumers aligned with the bucket that actually changes before final liquidation settlement.
