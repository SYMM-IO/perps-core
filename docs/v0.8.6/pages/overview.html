Symmio Core v0.8.6 Overview

Start here to read v0.8.6 as a set of targeted fixes: faster exits without removing withdrawal cooldown protections, cleaner AccountLayer and affiliate operations, and safer liquidation/freshness handling.

Use this page as the release-delta map. The release addresses faster withdrawals without bypassing the 12-hour safety model, clearer account and affiliate lifecycle controls, safer liquidation accounting, and a reconstructible allocated-balance event ledger for indexers.
