Symmio Core v0.8.6 Overview

Start here for a role-based route through all 31 release chapters, from protocol safety and settlement to AccountLayer, Express Withdrawal, integrations, and operations.

v0.8.6 is documented as 31 scoped release deltas plus two companion guides. Each chapter explains one durable behavior change, its boundary, and the integrations that must react. The companions provide this overview and the detailed Express operator runbook without inflating the numbered changelog.

How to use these notes

  1. Use the release index to search all numbered chapters and follow their release order.
  2. Choose a reader path below when you need the smallest useful subset for a review or integration.
  3. Read linked pages together when one change supplies another change's safety or observability boundary.
  4. For Express Withdrawal implementation, read the system design before the operator runbook.

Complete change map

Express Withdrawal

Express Withdrawal System Design defines the provider, funding, risk, and settlement model. Express Deposit Removal removes the unrelated v0.8.5 AccountLayer deposit split. The operator runbook is the companion implementation reference.

Accounts and authorization

This group covers AccountLayer ownership, delegated account scope, InstantLayer authorization scope, AccountLayer behavior changes, POSITION partial fills, callback liveness, the owner getter rename, and InstantOpen execution changes.

Liquidation and margin safety

The release adds snapshot-backed PartyA liquidation, its single-step wrapper, stricter deallocation floors, one PartyA liquidation-fee recipient, PartyB suspension gates, cross-PartyB reserve enforcement, force-close request binding, a notional LF floor, and an Affiliate shutdown backstop.

Fees and settlement

This group covers solver rate fees, operational fees, market-open fee pricing, typed Clearing House settlement, bound-mode unified settlement, and per-quote close netting.

Funding, observability, and symbols

The remaining chapters document per-function UPNL validity windows, the allocated-balance event ledger, corporate-action adjustment, liquidation funding events, PartyB funding-update nonces, and lazy accumulated funding.
